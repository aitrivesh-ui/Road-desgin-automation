What you are testing

Two layers: Python 3 tools (no Civil 3D) and Civil 3D + Dynamo (full pipeline).

LayerToolsProves
Offlinerun_tests.bat, preflight, design_check_outputs.pyCSV contracts, IRC engines, BOQ math, manifest logic
Civil 3Dm8_run_all.py (or M1→M7 individually)Alignment, profile, corridor, volumes, markings, signs, BOQ, DPR manifest

M8 default run order

m1→m2→m3→m4→m0→m5→m6→m7

Handbook M06 (BOQ) = repo m7_boq_rollup.py. Handbook M07 (DPR) = repo m6_sheets_helper.py.

Prerequisites

  • Python 3.8+ on PATH (separate from Civil’s IronPython 2)
  • Run install.bat at repo root or civil3d_automation\install_tools.bat once
  • Autodesk Civil 3D 2022+ with Dynamo and IronPython 2 for Python Script nodes
  • Template DWG: layers from template/layers_bim.csv; assembly, corridor, EG/FG names match config/project.json
  • config/project.json (copy from project.example.json if missing)

Phase 1 — Install & unit tests (no Civil)

1

Install Python tool dependencies

From the repository root:

install.bat

Or from civil3d_automation:

install_tools.bat

Pass: pip installs requirements-tools.txt; config/project.json created if absent.

2

Run all unit tests

cd civil3d_automation
run_tests.bat

Pass: Ran 90+ tests … OK (exact count may grow). Any failure blocks Phase 2.

Phase 2 — Preflight & config validation

3

Validate paths and CSV headers

cd civil3d_automation
python tools\road_automation_preflight.py --validate "%CD%\config\project.json"

Pass: No lines starting with ERROR:. Exit code 0.

4

Strict data checks (recommended)

python tools\road_automation_preflight.py --validate "%CD%\config\project.json" --strict

Pass: At least 2 alignment PIs; profile stations strictly increasing; corridor regions not overlapping.

Phase 3 — Civil 3D template & Dynamo setup

5

Prepare template drawing

  • Create layers from template/layers_bim.csv (e.g. C-ROAD-ALIGN-HORZ, C-ROAD-MARK-THERMO)
  • EG and FG surfaces named in project.json → names.surfaces
  • Assembly name matches names.assembly (example: BasicLaneAssembly)
  • IRC:67 sign blocks referenced in csv/signage_schedule.csv exist in the DWG
  • MoRTH title block on layouts if testing M6 title attributes
6

Wire Dynamo graphs

For each module, add a Python Script node (engine: IronPython 2), paste the matching file from python/, and connect inputs per script header comments.

Minimum for full test: one graph hosting m8_run_all.py with:

  • IN[0] — absolute path to config\project.json
  • IN[1] (optional) — step list, e.g. m1,m2,m3,m4,m0,m5,m6,m7

Save .dyn files under dynamo/. Set Run mode to Manual.

No pre-built .dyn ships in the repo — you build graphs once per Civil/Dynamo version.

Module acceptance (detailed)

Run targeted unit tests from civil3d_automation before Civil QA on each module.

M1 — Alignment

python -m unittest tools.test_irc38_geometry tools.test_alignment_entities -v

Sample csv/alignment_pi.csv PI A2 (R=150 m @ 80 kph) should log IRC38_R_MIN WARN. With design.strict_log: true, critical radius → ERROR blocks M8.

M2 — Profile

python -m unittest tools.test_irc66_profile -v

Use csv/templates/profile_pvis_crest_short_vc.csv → expect IRC66_K_CREST. Sag drainage fixture → IRC73_DRAINAGE.

M3 — Corridor regions + IRC:37

python -m unittest tools.test_irc37_engine tools.test_m4_region_volumes -v

After M3: out/irc37_layers.json or cache path in project.json.

M4 — Volumes & earthwork

python -m unittest tools.test_swell_shrinkage -v
  • Ordinary soil: cut_haul_m3 ≈ cut_m3 × 1.25
  • fill_borrow_m3 ≈ fill_m3 / 0.90
  • out/mass_haul_meta.json includes economic_lead_m

M0 — Markings

python -m unittest tools.test_m0_marking_qty -v

Requires M1 curve_table. In Civil: CL-D 3 m / 5 m dashes; no-passing → CL-DY; idempotent XData IRC35_ROAD_MARK_V2.

M5 — Signage

python -m unittest tools.test_m5_signage_schedule -v
python python\m5_build_signage_schedule.py --project config\project.json

Auto schedule needs M1 curve table + M4 fill depth for guardrails. Run M4 before M5 when guardrails required.

M6 — DPR manifest (offline)

python python\dpr_sheet_core.py --project config\project.json
python -m unittest tools.test_m6_dpr_manifest -v

L=1400 m → 3 PP sheets (500 m each). PDF: out/pdf/publish.scr — run SCRIPT in Civil manually.

M7 — BOQ

python -m unittest tools.test_m7_boq_rollup -v

Set boq.state_code (e.g. HR, UP) for state SOR from config/state_sor_rates.json.
