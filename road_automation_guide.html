Prerequisites & Installation

Setup ›

What you need

SoftwareNotes
Autodesk Civil 3D 2022+Required for M1–M15 (Dynamo runs inside Civil 3D)
Dynamo for Civil 3DBundled with Civil 3D — check it is enabled in Add-ins
Python 3.8+For M16–M20 and all tools. Install from python.org — add to PATH
GitTo clone the repository

Clone the repository

git clone https://github.com/aitrivesh-ui/road-desgin-automation.git
cd road-desgin-automation

Install Python dependencies

On Windows, double-click install.bat at the repo root, or run in a terminal:

cd civil3d_automation
pip install -r requirements-tools.txt

This installs openpyxl (for Excel workbook generation and M19 report) and any other tool dependencies.

✅
Once pip install completes with no errors, you're ready to proceed.

Set Up Your Project

Setup ›

Every automation run is driven by a single config/project.json file. The easiest way to create it is the Setup Wizard.

Option A — Setup Wizard (GUI)

cd civil3d_automation
python tools\setup_wizard.py

Fill in the four tabs — Project info, Civil 3D names, Styles, Design parameters — then click Generate project.json + run preflight.

Option B — CLI wizard

python tools\setup_wizard.py --cli

Option C — Copy the example

copy config\project.example.json config\project.json

Then open it in any text editor and update the values.

Key fields to set

KeyWhat to enter
names.alignmentExact name of your Civil 3D alignment object
names.corridorExact name of your corridor object
names.assemblyAssembly name that exists in your template DWG
names.surface_egExisting-ground surface name (e.g. EG)
design.plan_scalePlan sheet scale denominator (e.g. 1000 for 1:1000)
design.max_grade_pctQA upper grade limit (%)
💡
All paths in project.json are relative to the civil3d_automation folder (the package root), not to the JSON file itself.

Set up the template DWG

Run the AutoLISP setup script once on a blank DWG to create all required layers:

  1. Open a blank DWG in Civil 3D.
  2. At the AutoCAD command line, type: (load "path/to/setup_template.lsp")
  3. The script creates 13 layers (C-ALIGN, C-PROF-FG, C-ROAD-MARK, etc.) and sets drawing units to metres.
  4. Complete the 5 manual steps shown in the completion checklist (styles, assembly, sign blocks, EG surface).
  5. Save as your project .dwg or .dwt template.

DGPS Survey → CSV (optional)

Python ›

If your geometry comes from a DGPS survey file, skip manual CSV entry and generate all input CSVs automatically.

Supported formats

  • Generic CSV (point_id, easting, northing, elevation, code)
  • Trimble DC (.dc)
  • Leica GSI 8 / 16-word (.gsi)
  • LandXML (.xml)
  • Geographic (latitude, longitude — auto-projected)

Run the wizard

python tools\survey_to_csv.py

Or use the CLI

python tools\survey_to_csv.py --cli survey_data.csv

The tool auto-detects the file format and outputs alignment_pi.csv, profile_pvis.csv, section_widths.csv, and signage_schedule.csv ready for M1–M5.

✅
After this step, skip the manual CSV fill (step 3) — the survey tool has done it for you.

Preflight Validation

Python ›

Always run preflight before opening Civil 3D. It catches missing columns, bad paths, and data errors in seconds.

Basic check (headers + file paths)

cd civil3d_automation
python tools\road_automation_preflight.py --validate "%CD%\config\project.json"

Strict check (adds data quality rules)

python tools\road_automation_preflight.py --validate "%CD%\config\project.json" --strict

Strict mode also checks: minimum 2 alignment PIs, strictly increasing profile stations, no overlapping corridor regions.

GUI mode

tools\run_preflight.bat

What to look for

PrefixMeaningAction
OK:Check passedNothing to do
WARN:Optional key missingAdd to project.json if module needed
INFO:Output file not yet createdNormal before first run
ERROR:Problem that will fail the pipelineMust fix before running
🚫
Do not proceed to Civil 3D if preflight shows any ERROR: lines. Exit code 1 means errors exist.

Open the Pipeline Launcher

Python ›

The Pipeline Launcher is your single control panel for all M1–M20. Open it now — keep it open throughout the workflow.

cd civil3d_automation
python tools\pipeline_launcher.py

The three tabs

TabWhat it does
Select ModulesCheckboxes for all M1–M20. Two columns: Civil 3D (blue) and Python tools (green). Use Select-all / Clear-all / group shortcuts.
Dynamo (M1–M15)Shows a live step-filter string matching your selection. Click Copy to clipboard to copy it for Dynamo Player IN[1].
Python Tools (M16–M20)Run selected Python tools directly. Status badges show waiting / running / done / error. Output streams to the log panel.

Before running — set project.json path

On the Select Modules tab, click Browse… next to project.json and select your config/project.json. The status bar at the bottom confirms the active file.

💡
You can run only the modules you need. For example: check only M16–M18 to redo pavement and drainage after a design change, without re-running Civil 3D.

Run M1–M15 in Civil 3D (Dynamo)

Civil 3D ›
  1. In the Pipeline Launcher → Select Modules tab, tick all Civil 3D modules you want to run (default: all M1–M15).
  2. Click the Dynamo (M1–M15) tab — the step-filter string updates automatically.
    m1,m2,m3,m4,m5,m6,m7,m9,m10,m11,m12,m13,m14,m15
    Click Copy to clipboard.
  3. Open your project DWG in Civil 3D.
  4. Open Dynamo Player (Manage → Dynamo Player).
  5. Load the graph that contains m8_run_all.py as its Python Script node.
  6. Set IN[0] to the absolute path of your config\project.json, e.g.:
    C:\Projects\Demo\civil3d_automation\config\project.json
  7. Set IN[1] to the step-filter string you copied. Leave blank to run all M1–M15.
  8. Click Run in Dynamo Player.

Recommended run order

First runStep filterWhy
Geometry buildm1,m2,m3,m4Creates alignment, profile, corridor, and volumes before anything else
Output generationm5,m6,m7,m9,m10,m11Signage, markings, sections, superelevation after corridor exists
Sheets & analysism12,m13,m14,m15Mass haul and sheet layouts after volumes are computed
Full re-run*(blank)*Runs everything M1–M15 in order

Individual module re-runs

Changed only one CSV? Run just that module to save time:

What changedStep filter
Alignment PI coordinatesm1
Profile gradesm2
Lane/shoulder widthsm3,m4
Road markingsm9
Superelevationm11
Volumes (after corridor edit)m4,m7,m12
⚠️
M1 and M2 will error if an alignment/profile with the same name already exists in the drawing. Delete or rename the existing Civil 3D object before re-running M1 or M2.

Check the QA log after running

Open out\qa\run_log.txt — every step appends its output. A successful run shows OK: lines for each module.

Run M16–M20 Python Tools

Python ›

These tools run independently of Civil 3D — run them any time after your CSVs are ready.

Option A — Pipeline Launcher (easiest)

  2. Check the tools you want to run.
  3. Click Run selected Python 3 tools.
  4. Watch the status badges and log output.

cd civil3d_automation

Check Outputs & Verify Design

Verify ›

Run the design verifier (M20)

python tools\design_verifier.py config\project.json

M20 cross-checks every output file and prints a pass/fail report to out/design_verification.txt:

CheckWhat it verifies
AlignmentCurve radii ≥ minimum for design speed
ProfileGrades within max_grade_pct / min_grade_pct
VolumesCut/fill non-zero, cut:fill ratio flagged if >30% out of balance
PavementTotal thickness 200–1000 mm
DrainageHW/D ≤ 1.5; flags NO FIT catchments
BOQBOQ quantities consistent with volumes CSV (±10%)
Mass haulPeak surplus/deficit within reasonable bounds

Exit code 0 = PASS  |  Exit code 1 = at least one ERROR found.

Expected output files after a full run

  • 📄out/volumes.csv — corridor cut/fill volumes (M4)
  • 📄out/boq.csv — bill of quantities (M7)
  • 📄out/sections_list.csv — cross-section station list (M10)
  • 📄out/mass_haul.csv — cumulative net volume (M12)
  • 📄out/pavement_design.csv — layer thicknesses (M16)
  • 📄out/drainage_design.csv — culvert schedule (M17)
  • 📄out/intersection_geometry.csv — intersection calcs (M18)
  • 📊out/report/design_report.xlsx — full Excel report (M19)
  • 📋out/design_verification.txt — pass/fail (M20)
  • 🗒️out/qa/run_log.txt — Dynamo run log (M8)

Post-run output check

python tools\design_check_outputs.py "%CD%\config\project.json"

Module Reference

Reference ›

Civil 3D / Dynamo — M1–M15

M1
Alignment from CSV
Creates Civil 3D horizontal alignment with curves from alignment_pi.csv
M2
Profile from CSV
Creates finished-grade profile with K-values from profile_pvis.csv
M3
Corridor Regions
Applies lane/shoulder widths per corridor region from section_widths.csv
M4
Volumes
Rebuilds corridor and extracts cut/fill volumes to volumes.csv
M5
Signage
Inserts sign block references at correct stations from signage_schedule.csv
M6
Sheets Helper
Exports alignment geometry manifest for sheet layout
M7
BOQ Rollup
Compiles bill of quantities from volumes, markings, and signage
M9
Road Markings
Draws solid/dashed/arrow/transverse line markings on C-ROAD-MARK layer
M10
Cross-Sections
Creates SampleLineGroup + SampleLines + optional SectionView grid
M11
Superelevation
Assigns cross-fall via Civil 3D API; falls back to MText annotation table
M12
Mass Haul
Average-end-area diagram on C-MASSHAUL layer + mass_haul.csv
M13
Plan Sheets
Creates paper-space layouts PLAN-001, PLAN-002… tiling the alignment
M14
Long-section Sheets
ProfileView grid in model space for long-section sheet generation
M15
Standard Details
Imports block details from external DWGs into DETAILS layout

Python 3 Tools — M16–M20

M16
Pavement Design
Austroads empirical thickness + material selection. GUI + CLI
M17
Drainage Design
Rational method peak flow + Manning culvert sizing. GUI + CLI
M18
Intersections
Turn lane geometry, kerb return arcs, sight distance. GUI + CLI
M19
Report Generator
openpyxl multi-sheet Excel report with profile and mass haul charts
M20
Design Verifier
Cross-checks all output CSVs. OK / WARN / ERROR report. Exit code 1 on failure

Troubleshooting

Help ›
SymptomLikely cause & fix
ERROR: … missing column in preflightCSV header typo or extra space. Compare to Step 3 tables. Check for BOM if using Excel on non-Windows.
Strict: "at least 2 PI data rows"Only one row in alignment_pi.csv — add a second PI.
Strict: "station_m strictly increasing"Profile stations out of order or duplicated — sort and deduplicate.
Strict: "overlapping regions"section_widths station ranges overlap — adjust end_sta of earlier region.
ERROR: Alignment not found: MAIN-CLnames.alignment in project.json doesn't match the Civil 3D object name exactly (case-sensitive).
M4 volumes all zeroEG or FG surface missing in DWG, or surface names don't match names.surface_eg/fg in project.json.
M9: marking entity not createdBlock definition MARK_<type> not in DWG for arrow types. M9 logs WARN and continues — solid line used as fallback.
M10: SectionView not createdSectionView API varies by Civil 3D version. M10 logs NOTE and skips — sample lines are still created.
M16 KeyErrorpavement_inputs.csv is missing a required column. Run preflight first.
M17: NO FIT in drainage outputPeak flow exceeds the largest culvert (3000 mm). Use a box culvert or twin pipes.
M19: ImportError: openpyxlRun pip install openpyxl or re-run install_tools.bat.
Dynamo: "CSV not found"Wrong absolute path in IN[0], or paths in project.json not relative to civil3d_automation root.
Pipeline launcher: tools not runningCheck the project.json path shown in the status bar at the bottom of the launcher.

Still stuck?

Check out/qa/run_log.txt for the last Dynamo run output. Each module appends its full output string, including any Python traceback.
